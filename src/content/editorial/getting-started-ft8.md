FT8 has revolutionized amateur radio by bringing weak-signal digital communication to a wide audience. Developed by Joe Taylor, K1JT, and Steve Franke, K9AN, FT8 can decode signals well below the noise floor.

## What You Need

- An HF transceiver with USB audio or CAT control
- A computer running WSJT-X
- Audio cables or a built-in USB audio codec
- An accurate computer clock synchronized through NTP

## Setup

1. Install WSJT-X from the official project website.
2. Configure the radio connection using CAT control or VOX.
3. Set the audio levels so the waterfall has a blue background with green and yellow signals.
4. Synchronize the computer clock to within one second.
5. Start on 20 meters at 14.074 MHz USB, one of the most active FT8 frequencies.

## Making a QSO

FT8 contacts follow a structured exchange: CQ, call sign, grid square, signal report, RR73, and 73. Each transmission is exactly 15 seconds. The software handles the sequence after you select a CQ.

With a modest station—100 watts and a wire antenna—you can work stations around the world. FT8 is an approachable way to build a logbook and chase DXCC.
